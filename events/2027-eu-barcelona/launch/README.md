# Launch kit

Everything needed to announce the event, in one place. The launch kit is also the first place the theme is used, so it's designed right after it.

**Work in progress:** [Google Drive](https://drive.google.com/drive/folders/10UNcSu6fb4xXvHCOuWO0ZrPMFtKL0Q9a). Only finished, signed-off files go here.

## What to make

| File | Size |
| --- | --- |
| X banner | 1500 x 500 px |
| X post | 1600 x 900 px (16:9, also works for Bluesky and Mastodon) |
| LinkedIn page banner | 1128 x 191 px |
| LinkedIn post | 1200 x 627 px |
| Bluesky banner | 1500 x 500 px |
| Mastodon banner | 1500 x 500 px |
| Instagram post | 1080 x 1350 px (4:5). Instagram's profile grid crops to 3:4, so keep text and logos away from the edges. |
| Pretix header (ticket shop) | 1140 x 120 px, or 1170 px wide or more if it's shown full size |
| Sessionize banner (call for speakers) | Sessionize doesn't publish a size, so check the event settings in Sessionize first |

Sizes last checked 25 November 2026. Platforms change them often, so check again before you start.

Sessionize can also make a social banner for every speaker from a background image you upload, so a plain theme background is worth adding here too.

## Delivering

- **Format:** PNG, sRGB, at exactly the size above
- **Editable files:** Illustrator (AI), in a `source/` folder here
- **Name like:** `rejekts-<year>-<region>-<city>-x-banner-1500x500.png`
