# Theme

The look for this event, built on the Rejekts [brand guidelines](../../../foundations/brand/). Everything else is designed from it, so it comes first.

**Work in progress:** [Google Drive](https://drive.google.com/drive/folders/10UNcSu6fb4xXvHCOuWO0ZrPMFtKL0Q9a). Only finished, signed-off files go here.

## What the theme includes

| File | Size | Formats |
| --- | --- | --- |
| Backgrounds | 16:9 (1920 x 1080), square (1080 x 1080), portrait (1080 x 1350) and banner (1500 x 500) | PNG |
| Key visual or pattern | Vector | SVG and PNG (2000 px) |
| Theme sheet: colours in HEX and CMYK, fonts, and how the pattern and backgrounds are used | A4 | PDF |

The [launch kit](../launch/) shows the theme in use, so the two are designed together.

- **Editable files:** Illustrator (AI), in a `source/` folder here
- **Name like:** `rejekts-<year>-<region>-<city>-theme-background-1920x1080.png`
