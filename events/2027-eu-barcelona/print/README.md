# Print

Everything that goes to a printer or supplier: badges, lanyards, signage and swag.

**Work in progress:** [Google Drive](https://drive.google.com/drive/folders/10UNcSu6fb4xXvHCOuWO0ZrPMFtKL0Q9a). Only finished, signed-off files go here.

## Who does what

- **The organiser team** books the vendors, confirms sizes and sets the timelines and deadlines. They share these with the design team well ahead of time, so there's enough lead time to get everything done.
- **The design team** can start print files before sizes are confirmed. Most of the work is the design itself, and the sizes can be adjusted once the vendor confirms them.
- **Something missing or unclear?** Open an issue on GitHub, or comment on the pull request, so everyone can see the answer.

## Rules for every print file

- **Deliver:** a print-ready PDF (PDF/X-4) at the confirmed size, plus a PNG preview so people can see it without opening the PDF
- **Bleed:** as the vendor asks, usually 3 mm (0.125 in)
- **Colour:** CMYK. Rejekts Red is CMYK 0 100 100 0, or Pantone 485 C when the vendor prints spot colours.
- **Fonts:** converted to outlines or embedded
- **Photos:** 300 dpi at the final size
- **Editable file:** the Illustrator or InDesign file, in a `source/` folder next to the finals
- **The vendor's template wins.** If a vendor sends a template, use it.
- **Name like:** `rejekts-<year>-<region>-<city>-badge-qr-<size>.pdf`

## What goes in each folder

| Folder | What goes in it |
| --- | --- |
| `badges` | Front: logo, a blank space for the name, sponsor logos. Back: schedule QR code, socials, website, hashtag. With and without the QR code. |
| `lanyards` | Lanyard artwork for both sides, plus a separate logo strip if the vendor asks for one |
| `signage` | Everything that hangs or stands at the venue: roll-ups, table-top signs, posters, directional and room signs, arrows, the podium front and banners. The venue and vendors tell the organiser team what they need. |
| `swag` | T-shirts, stickers, tote bags and any other swag, each in its own folder. Vector PDF and SVG with text outlined, plus a PNG mockup. Stickers need the cut line on its own layer. |
