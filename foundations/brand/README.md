# Rejekts brand guidelines

**Version 0.1, November 2026.** What's settled so far, laid out the way most brand guides are. More detail comes with the foundations work in 2027.

The same values apply to **every Rejekts event, in every country**. Use HEX or RGB on screens, CMYK for print, and Pantone for spot colour.

## 1. Colour

### Core palette

| Colour | HEX | RGB | CMYK | Pantone | Use it for |
| --- | --- | --- | --- | --- | --- |
| **Rejekts Red** | #E30613 | 227 6 19 | 0 100 100 0 | 485 C (coated), 485 U (uncoated) | The logo, accents, bars, hashtags |
| **Rejekts Black** | #1D1D1B | 29 29 27 | 0 0 0 100 | Black C | Text, the logo's three dots |
| **White** | #FFFFFF | 255 255 255 | 0 0 0 0 | None (paper) | Backgrounds, text on red |

### Supporting greys

| Colour | HEX | RGB | CMYK | Pantone | Use it for |
| --- | --- | --- | --- | --- | --- |
| Grid grey | #F3F3F3 | 243 243 243 | 0 0 0 6 | None | The background square pattern |
| Light grey | #EAEAEA | 234 234 234 | 0 0 0 11 | None | Panels, dividers |
| Mid grey | #C4C4C4 | 196 196 196 | 0 0 0 31 | None | Borders and lines, never text |

### Using colour

- Keep layouts mostly white or black, with **red as the accent**.
- Use the colours exactly as listed. Don't create tints, shades or gradients of the logo colours.
- Print 100% black (CMYK 0 0 0 100) for text and logos, not a rich black mix.

### Why the red has more than one code

- The real Rejekts red is the ink: **CMYK 0 100 100 0**, or **Pantone 485** as a spot colour.
- On screen we show it as **#E30613**, which is how Illustrator previews that ink with European colour settings. With North American settings the same ink previews as #ED1C24. That's the same red seen through a different setting, so we don't use it.
- Where the event is doesn't matter. Screens show #E30613 the same everywhere, and every printer gets CMYK 0 100 100 0 and applies their own local profile.
- **#FF0000**, used on the website today, is pure screen red. It's brighter than ink can print, so the website will move to #E30613 to match print.

### Illustrator setup

1. Keep Edit > Color Settings on **Europe General Purpose**.
2. Make global swatches: **Rejekts Red** (CMYK 0 100 100 0) and **Rejekts Black** (CMYK 0 0 0 100).
3. SVG and PNG exports come out as #E30613 and #1D1D1B on their own.

Working with North American colour settings? Your exports will show the red as #ED1C24. Change it to #E30613 in your screen files, or switch Color Settings to Europe General Purpose.

## 2. Logo

The Rejekts logo is the red "rejected" X with three dots inside, next to the wordmark **Cloud_Native Rejekts**. Always use the supplied files; never retype the wordmark in a font.

### Versions

| Version | Use it on |
| --- | --- |
| **Colour** | White and light backgrounds. The default. |
| **Reverse** | Black and dark backgrounds |
| **Black** (one colour) | Single-colour print on light materials, such as lanyards and stamps |
| **White** (one colour) | Single-colour print on dark materials, and over photos |

### Layouts

| Layout | Use it when |
| --- | --- |
| **Horizontal** | There's more width than height. The default. |
| **Stacked** | The space is closer to square, such as avatars, badges and stickers |
| **Icon** (the X on its own, coming 2027) | Very small spaces: favicons, app icons, social avatars |

### Event tag

Each event adds a short red tag after the wordmark, such as **[EU'27]**, set in Source Code Pro. One plain Rejekts logo without a tag is coming with the foundations work.

### Clear space

Leave empty space around the logo at least as tall as the capital **R** in "Rejekts", on every side. No text, images or edges inside that space.

### Minimum size

| Layout | Print | Screen |
| --- | --- | --- |
| Horizontal | 30 mm wide | 150 px wide |
| Stacked | 25 mm wide | 120 px wide |

Below these sizes, use the icon instead.

### Don't

- Stretch, squash or rotate the logo
- Change its colours or use colours outside the palette
- Add shadows, outlines, glows or other effects
- Move, resize or remove parts of it
- Put the colour version on red or on busy photos (use reverse or white instead)
- Recreate the wordmark in a font

## 3. Typography

| Typeface | Use it for | Where to get it | If you can't install it |
| --- | --- | --- | --- |
| **Source Code Pro** | Headlines, the Rejekts look, short body text | Free and open (SIL Open Font License) on [Google Fonts](https://fonts.google.com/specimen/Source+Code+Pro); built into Google Docs and Slides via "More fonts" | Consolas, or Courier New |
| **Source Sans 3** | Longer reading text, where monospace gets tiring | Free and open on [Google Fonts](https://fonts.google.com/specimen/Source+Sans+3) | Arial |

- **Headlines:** Source Code Pro, Bold or Black, often in capitals
- **Body:** Source Code Pro Regular for short text, Source Sans 3 Regular for long text
- Myriad Pro (used in older prospectuses) is a paid Adobe font, so it's being phased out. Use only open fonts so anyone can open our files.

## 4. Accessibility

Text should meet the [WCAG](https://www.w3.org/WAI/standards-guidelines/wcag/) AA contrast standard: 4.5:1 for normal text and 3:1 for large text (about 24 px, or 19 px bold).

| Combination | Contrast | Use for |
| --- | --- | --- |
| Black on white | 16.9:1 | Any text |
| Red on white, or white on red | 4.9:1 | Any text |
| Red on grid grey | 4.4:1 | Large text only |
| Red on black | 3.5:1 | Large text only |
| Mid grey on white | 1.7:1 | Never text; borders and lines only |

- Give every image and social graphic alt text.
- Don't rely on colour alone to carry meaning.

## 5. Look and feel

- The big X, used as a frame for photos
- Small red x marks as bullets and accents
- A grid of light grey squares in the background
- Solid red bars with white monospace text for places and dates
- Big, bold white headlines with a red shadow
- Big hashtags, like `#REJEKTS2027`

## 6. Files and formats

| Format | Use it for |
| --- | --- |
| SVG | Websites and anything that scales |
| PNG | Slides, documents, social posts (transparent background, 2000 px) |
| PDF | Printers, and opening in almost any app |
| AI | Editing in Illustrator |

## 7. Sponsors and partners

- Show sponsor logos in their own colours. Never recolour them to match Rejekts.
- Give every logo in the same tier the same visual size and the same clear space.
- When the Rejekts logo appears with sponsor logos, keep it separate and give it its own clear space.
