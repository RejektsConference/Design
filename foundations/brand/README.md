# Rejekts brand guidelines

**Version 0.1, November 2026.** What's settled so far, laid out the way most brand guides are. More detail comes with the foundations work in 2027.

The same values apply to **every Rejekts event, in every country**. Use HEX or RGB on screens, CMYK for print, and Pantone for spot colour.

## 1. Colour

### Core palette

| Colour | HEX | RGB | CMYK | Pantone | Use it for |
| --- | --- | --- | --- | --- | --- |
| **Rejekts Red** | #E30613 | 227 6 19 | 0 100 100 0 | 485 C (coated), 485 U (uncoated) | The logo, accents, bars, hashtags |
| **Rejekts Black** | #1D1D1B | 29 29 27 | 0 0 0 100 | Black C | Text, the logo's three dots |
| **White** | #FFFFFF | 255 255 255 | 0 0 0 0 | None (paper) | Backgrounds, text on red |

### Supporting greys

| Colour | HEX | RGB | CMYK | Pantone | Use it for |
| --- | --- | --- | --- | --- | --- |
| Grid grey | #F3F3F3 | 243 243 243 | 0 0 0 6 | None | The background square pattern |
| Light grey | #EAEAEA | 234 234 234 | 0 0 0 11 | None | Panels, dividers |
| Mid grey | #C4C4C4 | 196 196 196 | 0 0 0 31 | None | Borders and lines, never text |

### Using colour

- Keep layouts mostly white or black, with **red as the accent**.
- Use the colours exactly as listed. Don't create tints, shades or gradients of the logo colours.
- Print 100% black (CMYK 0 0 0 100) for text and logos, not a rich black mix.

### Why the red has more than one code

- The real Rejekts red is the ink: **CMYK 0 100 100 0**, or **Pantone 485** as a spot colour.
- On screen we show it as **#E30613**, which is how Illustrator previews that ink with European colour settings. With North American settings the same ink previews as #ED1C24. That's the same red seen through a different setting, so we don't use it.
- Where the event is doesn't matter. Screens show #E30613 the same everywhere, and every printer gets CMYK 0 100 100 0 and applies their own local profile.
- **#FF0000**, used on the website today, is pure screen red. It's brighter than ink can print, so the website will move to #E30613 to match print.

### Illustrator setup

1. Keep Edit > Color Settings on **Europe General Purpose**.
2. Make global swatches: **Rejekts Red** (CMYK 0 100 100 0) and **Rejekts Black** (CMYK 0 0 0 100).
3. SVG and PNG exports come out as #E30613 and #1D1D1B on their own.

Working with North American colour settings? Your exports will show the red as #ED1C24. Change it to #E30613 in your screen files, or switch Color Settings to Europe General Purpose.
