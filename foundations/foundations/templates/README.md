# Templates

Reusable files for future events, each print template in two versions so nobody has to convert anything:

| | Europe | North America |
| --- | --- | --- |
| Paper | A4, A3, A1 | Letter, Tabloid |
| Units | Millimetres | Inches |
| Bleed | 3 mm | 0.125 in |
| Badge | A6 (105 x 148 mm) | 4 x 6 in |
| Roll-up banner | 850 x 2000 mm | 33 x 80 in |

Social, speaker card, slide and video templates are the same everywhere. Coming with the foundations work in 2027.
