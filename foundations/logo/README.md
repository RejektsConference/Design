# Logo

The Rejekts logo is a red "rejected" X with three dots inside, next to the wordmark **Cloud_Native Rejekts** in bold monospace.

So far each event has had its own logo file, with a tag like `[EU'26]`. The plan is one **plain Rejekts logo with no event on it**, for the website, socials, GitHub and whenever several events run at once, plus a simple rule for adding each event's tag.

## What will live here

| Layout | Versions | Formats |
| --- | --- | --- |
| Horizontal | Colour, reverse, black, white | SVG, PNG, PDF, AI |
| Stacked | Colour, reverse, black, white | SVG, PNG, PDF, AI |
| Icon (the X on its own) | Colour, reverse, black, white | SVG, PNG, PDF, AI |

- **Colour:** for light backgrounds
- **Reverse:** colour, for dark backgrounds
- **Black / white:** one colour, for single-colour print and busy photos

Named like `rejekts-logo-horizontal-color.svg`. Until it's ready, use the latest event logo in [events](../../events/). How to use the logo (clear space, minimum size, don'ts) is in the [brand guidelines](../brand/).
