# Foundations

Foundations is the shared Rejekts design kit: the things every event uses, so no local team has to start from scratch.

| Folder | What's in it | Status |
| --- | --- | --- |
| [brand](brand/) | Brand guidelines: colour, logo use, type, accessibility, look and feel | Version 0.1: colours, logo rules and fonts settled |
| [logo](logo/) | The plain Rejekts logo, with no event on it, and the rules for event logos | Starts January 2027 |
| [templates](templates/) | Social, speaker, slides, print and video templates for Europe and North America | Starts January 2027 |

## The plan

- **Now:** Barcelona comes first. What we learn making Barcelona's files feeds into the kit.
- **From mid-January 2027:** Lexi Nadolski and a designer work through the logo, guidelines and templates together, at whatever pace works.
- **Loose aim:** the kit is ready around April or May 2027.

Nothing is scheduled from mid-December to mid-January.
