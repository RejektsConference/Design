# Contributing

Thank you for helping with Rejekts design! Here's how to add your work.

1. **Put it in the right event folder**, such as `events/2027-eu-barcelona/social/`. See [events/README.md](events/README.md).
2. **Name it** `rejekts-<year>-<region>-<city>-<asset>-<variant>.<ext>`, lowercase with hyphens.
3. **Open a pull request.** If you don't use git, open the folder on GitHub, choose "Add file", then "Upload files", drag your files in and pick "Create a new branch".
4. **[Lexi Nadolski](https://github.com/LexiNadolski) reviews and signs off**, then it's merged.

## Quick checklist

- [ ] Right folder, right name
- [ ] Rejekts Red is #E30613 on screen and CMYK 0 100 100 0 in print ([foundations/brand](foundations/brand/))
- [ ] Dates, city and hashtag match the website
- [ ] Logos as SVG, PNG and PDF, with the source file
- [ ] Text is easy to read (good contrast)
- [ ] Nothing from the "never put in this repo" list in the [README](README.md)
