# Cloud Native Rejekts: design

Logos, event artwork, brand basics and templates for [Cloud Native Rejekts](https://cloud-native.rejekts.io), the b-side conference giving a second chance to great talks that didn't make it into KubeCon.

Everything is public on purpose, so any organiser, designer, speaker or sponsor can find the right file without having to ask.

## What's coming

- **foundations/**: what every event shares, starting with the brand guidelines
- **events/**: one folder per event, with everything made for it

## Never put in this repo

- Attendee data, such as badge name lists
- Sponsor contracts, pricing, quotes or invoices
- Sponsors or speakers who haven't been announced yet
- Fonts or images whose licence doesn't allow sharing
